# patientdata_statscodes
This repository contains extended patient demographic and clinical data and statistical codes used in this study.
All files are read-only, and all personal information - for example, author names and email addresses - was erased.
Immunohistochemistry and Western blot Raw Data Final.xlsx file contains raw data from signal quantification. All statistical analysis and figures were generated from the data in this file.
Table 1-3.docx file contains extended versions of Tables 1-3 of this study.
R codes.R file is a Script that contains all the R codes necessary to reproduce the ordinal logistic regression analyses, CNPase and MBP effect plots and CNPase and MBP regression plots. The data used in this R script were from the immunohistochemical quantification of CNPase and MBP expression in severe TBI and control tissues. After being loaded into R, the script can be run by pressing the following: Ctrl + Shift + Enter.
